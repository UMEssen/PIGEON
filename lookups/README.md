# Lookup Tables

This directory should contain the medical code catalog files used by the pipeline.
These files are **not included** in the repository due to licensing — download them from official sources.

## Required Files

### 1. `icd10gm_lookup_merged.csv`

**Source**: [BfArM ICD-10-GM](https://www.bfarm.de/DE/Kodiersysteme/Klassifikationen/ICD/ICD-10-GM/)

Download the ICD-10-GM classification (German Modification) and create a CSV with columns:

| Column | Description | Example |
|--------|-------------|---------|
| `icd10gm_code` | ICD-10-GM code | `C34.1` |
| `display` | Official display name (German) | `Bösartige Neubildung: Oberlappen (-Bronchus)` |

### 2. `icd10gm_lookup_with_jargon.csv`

Extended version of the ICD-10 lookup with doctor jargon variants.

| Column | Description | Example |
|--------|-------------|---------|
| `icd10gm_code` | ICD-10-GM code | `C34.1` |
| `display` | Official display name | `Bösartige Neubildung: Oberlappen (-Bronchus)` |
| `doctor_jargon` | Python list string with 3 jargon variants | `"['Oberlappenkrebs', 'OL-Ca', 'Bronchialkarzinom OL']"` |

> **Generating jargon**: You can generate the `doctor_jargon` column using an LLM by prompting it to create 3 colloquial German medical terms for each ICD code. These should reflect how doctors actually write diagnoses in clinical notes (abbreviations, common terms, informal descriptions).

### 3. `ops_lookup_merged.csv`

**Source**: [BfArM OPS](https://www.bfarm.de/DE/Kodiersysteme/Klassifikationen/OPS-ICHI/OPS/)

| Column | Description | Example |
|--------|-------------|---------|
| `code` | OPS procedure code | `5-399.5` |
| `display` | Official display name (German) | `Andere Operationen an Blutgefäßen` |

### 4. `atc_lookup_merged.csv`

**Source**: [BfArM ATC](https://www.bfarm.de/DE/Kodiersysteme/Klassifikationen/ATC/) or [WHO ATC/DDD Index](https://www.whocc.no/atc_ddd_index/)

| Column | Description | Example |
|--------|-------------|---------|
| `atc_code` | ATC classification code | `C09AA05` |
| `display` | Medication display name (German) | `Ramipril` |

## Directory Structure After Setup

```
lookups/
├── README.md                              # This file
├── icd10gm_lookup_merged.csv              # ~14,000 rows
├── icd10gm_lookup_with_jargon.csv         # ~14,000 rows (with 3 jargon variants each)
├── ops_lookup_merged.csv                  # ~30,000 rows
├── atc_lookup_merged.csv                  # ~6,000 rows
├── vectorstore_cache/                     # Auto-generated FAISS index for ICD-10
├── vectorstore_cache_atc/                 # Auto-generated FAISS index for ATC
└── vectorstore_cache_ops/                 # Auto-generated FAISS index for OPS
```

The `vectorstore_cache*` directories are auto-generated by Stage 6 (RAG correction) on first run.
